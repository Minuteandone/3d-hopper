What is this?

This is a clean-room playable reimplementation of the E3 2010 Tech Demo: 3D Hopper. It does not emulate the original ARM executable. Instead, it reads the original prototype's asset filesystem in your browser and uses those decoded textures in a new Three.js game implementation.
